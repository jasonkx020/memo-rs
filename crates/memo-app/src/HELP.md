# 分布式备忘录 · 使用说明

## 核心概念

- **密钥对 = 身份**：公私钥标识「你是谁」。换机导入同一密钥对即可认领异地托管的私人数据。
- **别名（姓名）**：只是本节点上对该密钥对的显示名，可改，不改变身份。
- **登录密码**：生成或导入身份时须设置（两次确认，至少 6 位）。用于进入应用、密封本机私钥（`secret.key`）、加密数据备份（`.memobak`）。**不**加密 `.memokey`。每次进入须输入；锁定后再进仍须输入。可在 **设置 → 本机 → 修改登录密码** 更换。忘记则无法恢复（请保管好 `.memokey`）。
- **`.memokey` 密钥包**：导出时**无导出密码**，内含明文私钥与 Ed25519 签名；导入时验签防篡改。须妥善保管文件（等同私钥）。旧版加密包导入时仍需「旧版包口令」，并另设本机登录密码。
- **私密 / 公开**：私密备忘以密文托管到其他节点（对端不可解）；公开备忘在局域网同步可读。

## 分类壳层

主界面顶栏页签为 **任务 / 备忘 / 私密 / 回收站**（默认任务）。身份菜单右侧是这四个入口；回收站为弱化图标。顶栏其余为身份菜单、自动锁定、搜索，以及「同步」「节点」「设置」「锁定」。右侧节点树默认关闭，点顶栏「节点」打开后，树顶显示 **N 节点在线**。中间为业务内容 + 右侧详情（任务页为月历与当天栏）。

- **任务**：有开始日的备忘（非账号、非性别私密）画在月历上；格内可点色块打开详情，`+N 更多` 展开当日列表。未完成且已过截止日的显示过期预警（顶栏横幅 + 右侧红卡），今天到期为橙色预警；可点「查看过期任务」。选中后右侧为事件详情（改期 / 标记完成）。无日期的随手记在右侧「未安排」，可「放到今天」。侧栏黄历为**都市上班宜忌**精简版（签约/出行/修造/剃头等）；社区版宜忌各显示约 2 条，商业版（`license.json`）可看更多，不提供完整传统黄历。
- **备忘**：账号密码与证件等私密条目只出现在此页；保存时强制私密、不上日历、不进未安排。
- **私密**：性别私密专属页（经期 / 体检）。
- **回收站**：软删备忘可恢复或彻底清除（约 30 天宽限）。

分类（待办/工作/生活等）仍可在表单里选择，只影响色标，不再占用顶栏。

**新建备忘**：点「+」弹出新建窗口填写。用「这是」选择 **某一天 / 好几天 / 先记着 / 备忘**；好几天需填结束日（≥开始日）。分类下拉仍可选。有到期时可设**提前提醒**（到期时 / 提前 1 / 3 / 7 天）。「性别私密」与「备忘」保存时强制加密。保存成功后弹窗自动关闭。

**编辑备忘**：详情点「编辑」进入同款表单，可改类型/日期/提醒/优先级/标签/正文；保存后写回本条。

**桌面便签**：在任务页当天列表或备忘列表侧对备忘右键，选「生成桌面便签」，会弹出无系统标题栏、可拖动、置顶的小窗。可直接改标题与正文，停顿约 0.8 秒后自动写回本条备忘（走与主界面相同的同步/备份路径）。同一条再次右键会聚焦已有便签；点 × 关闭。打开列表与窗口位置尺寸保存在本机 `sticky_session.json`（按身份隔离，**不同步**到其它节点）；多端内容以备忘同步为准。锁定或切换身份前会落盘会话并关闭便签；解锁同一身份后按会话恢复。

**系统托盘**：关闭主窗口会隐藏到托盘，进程与便签/提醒继续运行。托盘菜单可「显示主窗口」或「退出」（退出前保存便签会话）。开机自启动见设置。

**新建模板**：各分类带可直接改填的模板。在任务页打开新建时默认选中日；在备忘页打开则按「备忘」类型处理。

### 到期提醒

- 到期字段为空表示**先记着**（无提醒，出现在任务页「未安排」）。「备忘」页条目无到期、不上日历。
- 可设提前 N 天提醒（0=到期当日该时刻）。进程运行时（含主窗隐藏到托盘）约每 30 秒扫描一次，通过 **Windows / macOS / Linux** 系统原生通知弹出；从托盘「退出」后无法再弹通知。
- 旧数据仅含日期 `YYYY-MM-DD` 的备忘按当天 **09:00** 解析。跨天请填结束日，提醒仍按**开始日**计算。

### 自动锁定

- 主界面无指针/键盘操作一段时间后自动回到身份选择（等同锁定）；时长在 **设置 → 外观 → 自动锁定** 中调整（默认 3 分钟，可选不自动锁定）。
- 顶栏灰色胶囊显示剩余时间（`mm:ss 后自动锁定`）；关闭自动锁定时不显示。
- 点顶栏「锁定」或菜单「切换身份」可立即锁定；锁定后面签关闭，解锁同一身份后按本机会话恢复。

### 开机自启动

- **设置 → 外观 → 开机自启动**：勾选「开机时启动 Memo」（Windows 写入当前用户 Run 注册表）。开机后进程以托盘方式启动（主窗可先隐藏），仍需解锁身份后才恢复便签。

### 顶栏同步

- 点「同步」：刷新发现/连接节点列表，并重新推送私人密文备份；状态条显示上次同步时间。
- 内容区状态条：上次同步 · 在线节点 · 待同步条数；并提示数据本地加密、仅同步已授权节点。

### 标签与完成

- 列表卡片左侧圆圈可勾选「完成」（标题删除线）；非「普通」优先级会在卡片上显示。
- 详情编辑可改分类、日期跨度、提前提醒、优先级、标签、完成状态与正文；保存时一并写入。

- **身份性别**（可选）：顶栏「设置」→「本机」→「当前身份性别」。**开通性别私密无需设置性别**。

- **性别私密**：人人可用（可为自己或伴侣记录）。顶栏「私密」进入后为**列表 + 详情**；列表**置顶**专属入口。点开后顶部可在 **「经期」|「体检」** 间切换（**两项可同时开启**，都开时显示分段；不需要的一侧可在右上角 **「设置」** 里关闭或再开，本机记住，数据不删）。**经期页**：深粉实填=已标经期（历史手标保留）、浅粉=**仅下一轮**预测经期、绿描边=该轮易孕、角标「排」=该轮排卵（易孕/排卵不按多周期重复）；右键/底栏标经期（**仅今天及历史日**）。**体检页**：角标「检」+ 倒计时；配色同台风预警（灰=已过，蓝→黄→橙→红表示越来越近，红=当天）。两端均可写当天备注。推算仅供参考。其下可新建其它私密备忘。临近时顶栏页签闪烁、「去看看」进入置顶入口。设置仅本机；内容强制加密。

## 首次使用

1. 选择数据盘（Windows 默认优先 **D:**，否则 **C:**）。
2. **生成**新密钥对，或 **导入** `.memokey` 备份。
3. 填写别名 → **必须导出**密钥到安全位置（可指向云盘同步文件夹）。
4. **设置本机登录密码**（两次确认）→ 导出无口令的 `.memokey`（含签名验真）→ 进入主界面。导入明文包时只需设本机登录密码；旧版加密包需先填「旧版包口令」再设本机密码。

若检测到旧版数据：请自行备份后确认清空，再重新初始化（不做旧版兼容迁移）。

旧版明文身份下次进入时会要求先设置登录密码（二次确认），之后本机私钥加密存放。

## 日常启动

启动后选定身份并输入**登录密码**进入。锁定或自动锁定后回到选人页，再次进入仍须输密码。

顶栏显示当前身份别名；点「锁定」或空闲达到设置的自动锁定时长后回到选密钥对界面。

## 私人备份与恢复

- 私密备忘在保存时会以密文 Push 到接受托管的节点（可在设置中关闭）。
- **导出加密备份**（`.memobak`）使用当前登录密码，无需另设备份密码。
- 硬件损坏后：新机 **导入同一 `.memokey`**（验签通过后设置本机登录密码）→ 进入后自动尝试从托管区恢复。
- 登录密码与密钥文件都丢失 ⇒ 私人数据无法恢复（无「找回密码」）。

## 节点与发现

- **设置 → 网络**：可开关 **局域网自动发现**（找别人）和 **显示本节点**（让别人找到自己；仅主机广播）。关闭发现后只连手填对端。
- 主界面**最右侧节点树**用顶栏「同步」与「设置」之间的「节点」开关显隐。可按节点勾选私人托管目标（未勾选限制时推送到所有可托管节点）。
- UDP `17000` 仅广播协议 v2：节点 ID、身份指纹、别名、是否接受托管等。
- 与旧版节点不互通；对端版本不匹配时会被忽略。
- 同网段需统一 **集群盐** `cluster_salt_hex`。

## 设置要点

- 设置分 **外观 / 本机 / 网络 / 备份**。
- **外观**：浅色 / 深色 / 跟随系统 / **柔美**（玫瑰雾面配色，长时间使用更柔和；默认跟随系统；切换后立即生效并自动保存）。
- **本机 · 当前身份性别**：可选；与「性别私密」开通无关。
- **本机 · 修改登录密码**：输入当前密码与新密码（二次确认）；改密后本机 `secret.key` 与 `.memobak` 使用新密码（`.memokey` 不受影响）。
- **局域网自动发现 / 显示本节点**、接受他节点托管、推送本身份私人备份（在设置 → 网络 / 备份）。
- 更改节点 ID / 端口 / 数据目录 / 集群盐后需重启。

## 安全提示

- **登录密码**保护本机 `secret.key` 与加密备份 `.memobak`；`.memokey` **无导出密码**，靠签名防篡改，请妥善保管文件。
- 托管节点只能看到密文与指纹元数据，不能解密他人私人正文。
- 请同时保管登录密码与 `.memokey` 备份。

## FAQ

- **发现不到节点**：检查同网段、同集群盐、防火墙放行 UDP 17000 / TCP 监听端口，且双方均为新版本。
- **headless**：`memo --headless --identity <指纹>` 或 `--identity-file path.memokey`（明文包直接导入后提示设本机登录密码；旧版加密包先问包口令）。
