# 分布式备忘录 · 使用说明

## 核心概念

- **密钥对 = 身份**：公私钥标识「你是谁」。换机导入同一密钥对即可认领异地托管的私人数据。
- **别名（姓名）**：只是本节点上对该密钥对的显示名，可改，不改变身份。
- **无日常密码**：启动时选择密钥对进入；会话锁定，中途不可切换（须退出后重选）。不需要每天输入主密码。
- **私密 / 公开**：私密备忘以密文托管到其他节点（对端不可解）；公开备忘在局域网同步可读。

## 分类壳层

主界面顶栏页签为 **日历 / 账号证件 / 私密 / 回收站**（默认日历）。身份菜单右侧是这四个入口；回收站为弱化图标。顶栏其余为身份菜单、自动锁定、搜索，以及「同步」「节点」「设置」「锁定」。右侧节点树默认关闭，点顶栏「节点」打开后，树顶显示 **N 节点在线**。中间为业务内容 + 右侧详情（日历页为月历与当天栏）。

- **日历**：有开始日的备忘（非账号、非性别私密）画在月历上；格内可点色块打开详情，`+N 更多` 展开当日列表。未完成且已过截止日的显示过期预警（顶栏横幅 + 右侧红卡），今天到期为橙色预警；可点「查看过期任务」。选中后右侧为事件详情（改期 / 标记完成）。无日期的随手记在右侧「未安排」，可「放到今天」。
- **账号证件**：账号密码与证件只出现在此页；保存时强制私密、不上日历、不进未安排。
- **私密**：性别私密专属页（经期 / 体检）。
- **回收站**：软删备忘可恢复或彻底清除（约 30 天宽限）。

分类（待办/工作/生活等）仍可在表单里选择，只影响色标，不再占用顶栏。

**新建备忘**：点「+」弹出新建窗口填写。用「这是」选择 **某一天 / 好几天 / 先记着 / 账号密码**；好几天需填结束日（≥开始日）。分类下拉仍可选。有到期时可设**提前提醒**（到期时 / 提前 1 / 3 / 7 天）。「性别私密」与「账号密码」保存时强制加密。保存成功后弹窗自动关闭。

**编辑备忘**：详情点「编辑」进入同款表单，可改类型/日期/提醒/优先级/标签/正文；保存后写回本条。

**桌面便签**：在日历当天列表或账号/列表侧对备忘右键，选「生成桌面便签」，会弹出无系统标题栏、可拖动、置顶的小窗（只读快照）。同一条再次右键会聚焦已有便签；点窗口右上角 × 关闭。锁定或退出身份后便签一并关闭。

**新建模板**：各分类带可直接改填的模板。在日历页打开新建时默认选中日；在账号页打开则按账号密码处理。

### 到期提醒

- 到期字段为空表示**先记着**（无提醒，出现在日历页「未安排」）。账号证件无到期、不上日历。
- 可设提前 N 天提醒（0=到期当日该时刻）。进程运行时（含最小化）约每 30 秒扫描一次，通过 **Windows / macOS / Linux** 系统原生通知弹出；完全退出后无法弹通知（不做托盘常驻）。
- 旧数据仅含日期 `YYYY-MM-DD` 的备忘按当天 **09:00** 解析。跨天请填结束日，提醒仍按**开始日**计算。

### 自动锁定

- 主界面无指针/键盘操作一段时间后自动回到身份选择（等同锁定）；时长在 **设置 → 外观 → 自动锁定** 中调整（默认 3 分钟，可选不自动锁定）。
- 顶栏灰色胶囊显示剩余时间（`mm:ss 后自动锁定`）；关闭自动锁定时不显示。
- 点顶栏「锁定」或菜单「切换身份」可立即锁定。

### 顶栏同步

- 点「同步」：刷新发现/连接节点列表，并重新推送私人密文备份；状态条显示上次同步时间。
- 内容区状态条：上次同步 · 在线节点 · 待同步条数；并提示数据本地加密、仅同步已授权节点。

### 标签与完成

- 列表卡片左侧圆圈可勾选「完成」（标题删除线）；非「普通」优先级会在卡片上显示。
- 详情编辑可改分类、日期跨度、提前提醒、优先级、标签、完成状态与正文；保存时一并写入。

- **身份性别**（可选）：顶栏「设置」→「本机」→「当前身份性别」。**开通性别私密无需设置性别**。

- **性别私密**：人人可用（可为自己或伴侣记录）。顶栏「私密」进入后为**列表 + 详情**；列表**置顶**专属入口。点开后顶部可在 **「经期」|「体检」** 间切换（**两项可同时开启**，都开时显示分段；不需要的一侧可在右上角 **「设置」** 里关闭或再开，本机记住，数据不删）。**经期页**：深粉实填=已标经期（历史手标保留）、浅粉=**仅下一轮**预测经期、绿描边=该轮易孕、角标「排」=该轮排卵（易孕/排卵不按多周期重复）；右键/底栏标经期（**仅今天及历史日**）。**体检页**：角标「检」+ 倒计时；配色同台风预警（灰=已过，蓝→黄→橙→红表示越来越近，红=当天）。两端均可写当天备注。推算仅供参考。其下可新建其它私密备忘。临近时顶栏页签闪烁、「去看看」进入置顶入口。设置仅本机；内容强制加密。

## 首次使用

1. 选择数据盘（Windows 默认优先 **D:**，否则 **C:**）。
2. **生成**新密钥对，或 **导入** `.memokey` 备份。
3. 填写别名 → **必须导出**密钥到安全位置（可指向云盘同步文件夹）。
4. 导出完成后进入主界面。

若检测到旧版数据：请自行备份后确认清空，再重新初始化（不做旧版兼容迁移）。

## 日常启动

启动后在列表中选定一个身份密钥对即可进入。本机已保存的密钥对无需密码；能操作本机的人即可选用机上身份——请保管好导出的 `.memokey` 文件。

顶栏显示当前身份别名；点「锁定」或空闲达到设置的自动锁定时长后回到选密钥对界面。

## 私人备份与恢复

- 私密备忘在保存时会以密文 Push 到接受托管的节点（可在设置中关闭）。
- 硬件损坏后：新机 **导入同一 `.memokey`** → 进入后自动尝试从托管区恢复。
- 密钥文件与导出保险口令都丢失 ⇒ 私人数据无法恢复（无「找回密码」）。

## 节点与发现

- **设置 → 网络**：可开关 **局域网自动发现**（找别人）和 **显示本节点**（让别人找到自己；仅主机广播）。关闭发现后只连手填对端。
- 主界面**最右侧节点树**用顶栏「同步」与「设置」之间的「节点」开关显隐。可按节点勾选私人托管目标（未勾选限制时推送到所有可托管节点）。
- UDP `17000` 仅广播协议 v2：节点 ID、身份指纹、别名、是否接受托管等。
- 与旧版节点不互通；对端版本不匹配时会被忽略。
- 同网段需统一 **集群盐** `cluster_salt_hex`。

## 设置要点

- 设置分 **外观 / 本机 / 网络 / 备份**。
- **外观**：浅色 / 深色 / 跟随系统 / **柔美**（玫瑰雾面配色，长时间使用更柔和；默认跟随系统；切换后立即生效并自动保存）。
- **本机 · 当前身份性别**：可选；与「性别私密」开通无关。
- **局域网自动发现 / 显示本节点**、接受他节点托管、推送本身份私人备份（在设置 → 网络 / 备份）。
- 更改节点 ID / 端口 / 数据目录 / 集群盐后需重启。

## 安全提示

- 信任本机使用者；防丢靠密钥文件外置保管（含云盘目录）。
- 托管节点只能看到密文与指纹元数据，不能解密他人私人正文。
- 导出时可设保险口令保护 `.memokey`（初始化时明文显示便于核对，可留空）；日常打开软件不需要该口令。

## FAQ

- **发现不到节点**：检查同网段、同集群盐、防火墙放行 UDP 17000 / TCP 监听端口，且双方均为新版本。
- **headless**：`memo --headless --identity <指纹>` 或 `--identity-file path.memokey`。
