# 分布式备忘录 · 使用说明

本说明已内置在程序中，无需联网或额外文件。

---

## 一、首次使用

1. 双击 `memo.exe` 启动（绿色免安装，无需装运行库）。
2. 首次启动需**设置主密码并再次确认**（两次须一致）。主密码用于解锁、编辑与删除确认，**不会明文保存在磁盘**；校验摘要保存在数据目录 `verifier.dat`。
3. 主密码解锁后，进入**人员登录**：选择人员并输入该人员密码；首次无人员时需创建首位人员。
4. 顶栏显示当前人员，可「切换」重新登录；「人员」可管理账号（增删改密、禁用）。

> 忘记主密码将无法解密已有数据，请自行妥善保管。人员密码仅用于身份切换，不能替代主密码。

---

## 二、备忘录操作

### 新建

- 点击右上角「新建」，填写标题与内容后点「添加」。
- 标题、内容支持中文输入。

### 查看

- 在左侧列表**单击**一条备忘即可在中间查看详情（默认只读）。
- 悬停列表时为手型光标，整行均可点击。

### 编辑

- 查看详情后点「编辑」，需再次输入主密码。
- 修改后点「保存」；「取消编辑」可放弃本次修改。

### 删除

- 在左侧列表条目上**右键** → 选择「删除…」。
- 须输入主密码确认；密码错误不会删除。
- 顶栏与详情区不常驻删除按钮，避免误触。

### 复制与导出

- 详情区可「复制全文」「复制标题」。
- 「导出」/「导出全部」会弹出确认框：**须输入主密码**，并指定保存路径（可点「浏览…」选择位置）。
- 导出文件为**明文 TXT**，请妥善保管。
- 默认建议路径在数据目录下的 `exports` 文件夹，可改为任意位置。

### 变更历史

- 备忘详情、任务详情、人员管理中均可点「历史」，查看本机审计时间线。
- 每条记录展示三要素：**谁**（当前登录人员）、**哪个节点**（版本所在节点）、**什么时候**（UTC 时间）。
- 来源标为「本地」或「同步自 …」；悬停可看完整时间与记录节点 id。
- 可选中两条记录对比差异（备忘为标题/正文；任务/人员为可读摘要）。
- **需先登录人员再修改**，才会记下操作人；未登录时显示「未记录操作人」。升级前的旧审计条目也无操作人，属正常。
- 历史基于本机 `audit.jsonl`，不汇总其他机器独有的输掉版本。

### 加密备份

- 「设置」中可「导出/导入加密备份」（`.memobak`），使用独立备份密码加密全部备忘。
- 备份密码可与主密码不同；导入会按备份内容写入本地库。

### 关于与版本

- 「帮助 → 关于」可查看产品名称、版本、授权状态、文件版本与版权信息。
- Windows：右键 `memo.exe` → **属性 → 详细信息**，同样可查看文件版本与版权。
- 可将签名后的 `license.json` 放到配置目录以显示商业授权（无文件时为社区版，功能不阻断）。

## 二（续）、日历与工作安排

左侧切换到「日历」Tab：

| 模式 | 说明 |
|------|------|
| 月历 | 左侧选日；中间宽幅展示当日任务；标注工作日/周末/法定假（休）/调休上班（班） |
| 周视图 | 中间全宽时间轴（约 8–20 点），点击色块打开任务详情 |
| 甘特 | 中间全宽人员×日条带，点击打开详情 |

- 右上角「新建任务」；任务详情可「← 返回总览」。
- 任务可设**开始日期时刻 / 结束日期时刻 / 工时**（支持跨日）；改结束会反推工时，改工时则结束日期时刻随动。
- 任务状态：未开始 / 进行中 / 暂停 / 阻塞 / 已取消 / 已结束（默认可改；阻塞表示卡在外部依赖）。
- 顶栏「节点」可展开/收起右侧节点栏，收起后中间区域更宽，便于阅读正文。
- 任务与备忘独立；编辑/删除任务同样需要主密码确认。
- 人员与任务会随局域网同步（需各方升级到支持版本）。

## 三、多机同步（局域网）

### 自动发现（推荐）

1. 各电脑安装/复制同一绿色版 `memo.exe`。
2. 使用**相同主密码**，并在「设置」中保证 **`salt_hex` 完全相同**。
3. 保持「局域网自动发现」开启（默认开启）。
4. 防火墙放行：
   - **TCP**：本机监听端口（默认 `7000`）
   - **UDP**：`17000`（发现用）
5. 数秒后，右侧「节点」列表应出现对方；底栏显示「发现 N · 在线 M · 通道 K」。
6. 任一侧新建或修改备忘，会按 LWW（最后写入获胜）规则同步。

### 在线状态与同步通道

- **在线 / 不稳定 / 离线**：由 **UDP 广播（Announce）** 判定（控制面），约每 2 秒一次；不是 TCP 心跳。
- **通道**：表示当前已建立 **TCP 同步连接**（数据面），用于全量/增量同步。
- 每对节点最多保留 **1 条 TCP**（按节点 ID 单边拨号并去重），避免网状双连接拥挤。

### 磁盘空间

- 各节点通过 UDP Announce 广播数据目录所在卷的**可用 / 总容量**；节点卡片与底栏可查看。
- **全量同步前**会估算所需空间（含审计落盘余量）；不足时拒绝同步并提示清理方式。
- 可用空间过低时也会拒绝增量合并，以免把磁盘写满导致无法使用。
- 腾出空间：清理无关大文件；把「数据目录」改到更大磁盘并迁移后重启；删除不需要的 `exports/` 与旧 `.memobak`；满盘时勿大量导入。

### 手动指定对端

- 跨网段或无法广播时：在「设置 → 对端列表」每行填写 `对方IP:端口`，保存后**重启**程序。

### 注意

- 同机开两个实例时，请使用**不同监听端口**，否则第二个会绑定失败。
- 不同 `salt_hex` 的节点不会自动互联（防止串群）。
- 同 salt 设备过多（≥16）时界面会提示，建议减少并发节点。

## 四、设置说明

打开右上角「设置」可修改：

| 项 | 说明 |
|----|------|
| 节点 ID | 本机在网络中的名称，建议各机不同 |
| 数据目录 | 加密数据与导出文件存放位置 |
| 监听端口 | TCP 同步端口，默认 7000 |
| 对端列表 | 手动 peers，每行 `host:port` |
| 局域网自动发现 | 是否广播/收听 UDP 17000 |
| salt_hex | 集群共享盐（32 位十六进制），同集群必须一致 |

更改节点 ID、端口、数据目录、盐或发现开关后，一般需要**重启程序**生效。

配置文件位置（Windows）：

`%AppData%\DistributedMemo\settings.json`

## 五、安全说明（简要）

- 内容使用 **AES-256-GCM** 加密存储。
- 密钥由主密码经 **Argon2id** 派生。
- 操作写入 **Ed25519** 审计链，底栏可查看审计是否完整。
- 同步仅在您配置/发现的节点之间进行，请勿把 `salt_hex` 泄露给无关人员。

## 六、常见问题

**Q：提示 ProcessPrng / bcryptprimitives.dll？**

A：请使用本仓库用 Rust 1.77.2 打出的绿色包（`pack-green.bat` / `dist\memo.exe`），勿用更新版 Rust 直接编译的 exe。

**Q：同网段发现不到对方？**

A：检查主密码与 `salt_hex` 是否一致；放行 TCP 端口与 UDP 17000；确认发现开关已开。

**Q：中文标题只能输入很少字？**

A：请使用较新绿色包（已修复 IME）。输入时拼音可能出现在系统候选框，确认后写入标题。

**Q：列表点文字选不中？**

A：请使用较新版本；整行均可点选，悬停应为手型。

**Q：命令行模式？**

A：`memo.exe --headless` 进入控制台；可用 `discover`、`peers` 等命令。
