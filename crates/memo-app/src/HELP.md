# 分布式备忘录 · 使用说明

本说明已内置在程序中，无需联网或额外文件。

---

## 一、首次使用

1. 双击 `memo.exe` 启动（绿色免安装，无需装运行库）。
2. 首次启动需**设置主密码并再次确认**（两次须一致）。主密码用于解锁、编辑与删除确认，**不会明文保存在磁盘**；校验摘要保存在数据目录 `verifier.dat`。
3. 之后启动只需输入一次主密码解锁，即可新建、查看备忘录。

> 忘记主密码将无法解密已有数据，请自行妥善保管。

---

## 二、备忘录操作

### 新建

- 点击右上角「新建」，填写标题与内容后点「添加」。
- 标题、内容支持中文输入。

### 查看

- 在左侧列表**单击**一条备忘即可在中间查看详情（默认只读）。
- 悬停列表时为手型光标，整行均可点击。

### 编辑

- 查看详情后点「编辑」，需再次输入主密码。
- 修改后点「保存」；「取消编辑」可放弃本次修改。

### 删除

- 在左侧列表条目上**右键** → 选择「删除…」。
- 须输入主密码确认；密码错误不会删除。
- 顶栏与详情区不常驻删除按钮，避免误触。

### 复制与导出

- 详情区可「复制全文」「复制标题」。
- 「导出」/「导出全部」会弹出确认框：**须输入主密码**，并指定保存路径（可点「浏览…」选择位置）。
- 导出文件为**明文 TXT**，请妥善保管。
- 默认建议路径在数据目录下的 `exports` 文件夹，可改为任意位置。

### 变更历史

- 详情区点「历史」可查看本机审计时间线：**何时**、**哪台节点**写入、创建/修改/删除。
- 可选中两条记录对比标题与正文差异（基于本机 `audit.jsonl`，不汇总其他机器独有的输掉版本）。

### 加密备份

- 「设置」中可「导出/导入加密备份」（`.memobak`），使用独立备份密码加密全部备忘。
- 备份密码可与主密码不同；导入会按备份内容写入本地库。

### 关于与版本

- 「帮助 → 关于」可查看产品名称、版本、授权状态、文件版本与版权信息。
- Windows：右键 `memo.exe` → **属性 → 详细信息**，同样可查看文件版本与版权。
- 可将签名后的 `license.json` 放到配置目录以显示商业授权（无文件时为社区版，功能不阻断）。

## 三、多机同步（局域网）

### 自动发现（推荐）

1. 各电脑安装/复制同一绿色版 `memo.exe`。
2. 使用**相同主密码**，并在「设置」中保证 **`salt_hex` 完全相同**。
3. 保持「局域网自动发现」开启（默认开启）。
4. 防火墙放行：
   - **TCP**：本机监听端口（默认 `7000`）
   - **UDP**：`17000`（发现用）
5. 数秒后，右侧「节点」列表应出现对方；底栏显示「发现 N / 在线 M」。
6. 任一侧新建或修改备忘，会按 LWW（最后写入获胜）规则同步。

### 手动指定对端

- 跨网段或无法广播时：在「设置 → 对端列表」每行填写 `对方IP:端口`，保存后**重启**程序。

### 注意

- 同机开两个实例时，请使用**不同监听端口**，否则第二个会绑定失败。
- 不同 `salt_hex` 的节点不会自动互联（防止串群）。

## 四、设置说明

打开右上角「设置」可修改：

| 项 | 说明 |
|----|------|
| 节点 ID | 本机在网络中的名称，建议各机不同 |
| 数据目录 | 加密数据与导出文件存放位置 |
| 监听端口 | TCP 同步端口，默认 7000 |
| 对端列表 | 手动 peers，每行 `host:port` |
| 局域网自动发现 | 是否广播/收听 UDP 17000 |
| salt_hex | 集群共享盐（32 位十六进制），同集群必须一致 |

更改节点 ID、端口、数据目录、盐或发现开关后，一般需要**重启程序**生效。

配置文件位置（Windows）：

`%AppData%\DistributedMemo\settings.json`

## 五、安全说明（简要）

- 内容使用 **AES-256-GCM** 加密存储。
- 密钥由主密码经 **Argon2id** 派生。
- 操作写入 **Ed25519** 审计链，底栏可查看审计是否完整。
- 同步仅在您配置/发现的节点之间进行，请勿把 `salt_hex` 泄露给无关人员。

## 六、常见问题

**Q：提示 ProcessPrng / bcryptprimitives.dll？**

A：请使用本仓库用 Rust 1.77.2 打出的绿色包（`pack-green.bat` / `dist\memo.exe`），勿用更新版 Rust 直接编译的 exe。

**Q：同网段发现不到对方？**

A：检查主密码与 `salt_hex` 是否一致；放行 TCP 端口与 UDP 17000；确认发现开关已开。

**Q：中文标题只能输入很少字？**

A：请使用较新绿色包（已修复 IME）。输入时拼音可能出现在系统候选框，确认后写入标题。

**Q：列表点文字选不中？**

A：请使用较新版本；整行均可点选，悬停应为手型。

**Q：命令行模式？**

A：`memo.exe --headless` 进入控制台；可用 `discover`、`peers` 等命令。
