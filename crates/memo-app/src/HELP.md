# 分布式备忘录 · 使用说明

## 核心概念

- **密钥对 = 身份**：公私钥标识「你是谁」。换机导入同一密钥对即可认领异地托管的私人数据。
- **别名（姓名）**：只是本节点上对该密钥对的显示名，可改，不改变身份。
- **无日常密码**：启动时选择密钥对进入；会话锁定，中途不可切换（须退出后重选）。
- **私密 / 公开**：私密备忘以密文托管到其他节点（对端不可解）；公开备忘在局域网同步可读。

## 首次使用

1. 选择数据盘（Windows 默认优先 **D:**，否则 **C:**）。
2. **生成**新密钥对，或 **导入** `.memokey` 备份。
3. 填写别名 → **必须导出**密钥到安全位置（可指向云盘同步文件夹）。
4. 导出完成后进入主界面。

若检测到旧版数据：请自行备份后确认清空，再重新初始化（不做旧版兼容迁移）。

## 日常启动

启动后在列表中选定一个身份密钥对即可进入。本机已保存的密钥对无需密码；能操作本机的人即可选用机上身份——请保管好导出的 `.memokey` 文件。

顶栏显示当前身份别名与指纹短码；点「退出」回到选密钥对界面。

## 私人备份与恢复

- 私密备忘在保存时会以密文 Push 到接受托管的节点（可在设置中关闭）。
- 硬件损坏后：新机 **导入同一 `.memokey`** → 进入后自动尝试从托管区恢复。
- 密钥文件与导出保险口令都丢失 ⇒ 私人数据无法恢复（无「找回密码」）。

## 节点与发现

- UDP `17000` 仅广播协议 v2：节点 ID、身份指纹、别名、是否接受托管等。
- 与旧版节点不互通；对端版本不匹配时会被忽略。
- 同网段需统一 **集群盐** `cluster_salt_hex`。

## 设置要点

- 对外广播本节点、接受他节点托管、推送本身份私人备份。
- 更改节点 ID / 端口 / 数据目录 / 集群盐后需重启。

## 安全提示

- 信任本机使用者；防丢靠密钥文件外置保管（含云盘目录）。
- 托管节点只能看到密文与指纹元数据，不能解密他人私人正文。
- 导出时可设保险口令保护 `.memokey`；日常打开软件不需要该口令。

## FAQ

- **发现不到节点**：检查同网段、同集群盐、防火墙放行 UDP 17000 / TCP 监听端口，且双方均为新版本。
- **headless**：`memo --headless --identity <指纹>` 或 `--identity-file path.memokey`。
